# 海外短剧素材库 · 架构规划 v1

**目标**：不是「攒一堆素材」，而是建一套**可组装的零件系统**——固定公式 + 标准化零件 = 稳定产出剧本。

**两个市场分开建，理由见 §2。**「东南亚」不能当成一个市场打包。

---

## 0. 先讲三个设计原则（决定后面所有字段）

### 原则一：素材必须带 ID，否则公式调不动

「霸总」「hacienda」「Hermes 皮带」这些东西如果只是文档里的段落，脚本和 LLM 都引用不了。
所有素材统一编码：

```
{MARKET}-{LAYER}-{NNN}

MX-SCN-014   墨西哥 · 场景 · 第14条
ID-OBJ-007   印尼 · 物品 · 第7条
```

市场码：`MX` 墨西哥 / `ID` 印尼 / `TH` 泰国 / `VN` 越南 / `PH` 菲律宾 / `MY` 马来西亚
层码见 §3。

有了 ID，公式才有意义：
> 第 3 集开场 = `ID-HOK-012` × `ID-SCN-004` × `ID-CHR-002`

### 原则二：每条素材必须标「可替换等级」S0–S3

这是整个库最值钱的字段。它回答一个现实问题：**国内剧本能不能直接翻译出海？**

| 等级 | 含义 | 处理方式 |
|---|---|---|
| `S0 KEEP` | 跨市场通用，直接可用 | 豪车、董事会、手机摔碎、验孕棒、监控录像 |
| `S1 SWAP` | 换皮即可，结构不变 | 人名、地名、节日、餐食、货币、称谓 |
| `S2 REBUILD` | 结构得重写 | 家庭权力结构、阶级符号、宗教逻辑、法律环境 |
| `S3 RED` | 禁区，碰了会死 | 见 §4 各国红线 |

**绝大多数出海团队翻车在 S2 上**——他们以为 S2 是 S1。
例：「甩离婚协议」在菲律宾根本没法拍，因为**菲律宾禁止离婚**（全球除梵蒂冈外唯一）。这类套路必须重写成 annulment（婚姻无效）或分居，整个戏剧张力来源都得换。

### 原则三：素材库只服务「一种公式」，不做大杂烩

一个库对应一条公式主线。先跑通「豪门/阶级跨越 + 打脸复仇」这条，跑通再横向加喜剧、悬疑。
混着建，组装时会互相打架，公式永远定不下来。

## 1. 分层结构

```
L0  市场底座  MARKET    ← 不可替换的硬约束：语言、宗教、法律、审查、审美
L1  现实素材  REALITY   ← 场景 / 地域 / 城市 / 物品 / 宗教文化 / 语言台词
L2  叙事要素  NARRATIVE ← 题材 / 人设 / 主角 / 配角 / 关系 / 主线 / 支线 / 爽点 / 钩子 / 镜头
L3  组装公式  FORMULA   ← 把 L1+L2 拼成剧本的规则
L4  产出      OUTPUT    ← 分集大纲 → 场景表 → 台词稿
```

**关键约束：L1 只描述「世界长什么样」，L2 只描述「故事怎么走」，两者不互相引用。**
这样才能做「同一个故事骨架 × 不同市场外壳」——一套主线复用到墨西哥和印尼。

## 2. 为什么墨西哥和东南亚必须拆开建

### 墨西哥（MX）—— 单市场，但类型传统极强

- **母类型是 telenovela**，不是中国霸总。三大祖传母题：`阶级跨越（pobre→rica）`、`隐藏身份（gemelas / 秘密出生）`、`复仇（venganza）`。这三条正好能跟国内霸总对齐，是移植成本最低的市场。
- **阶级符号极其直白且可视化**：肤色、口音（ norteño / chilango / sureño ）、皮卡 vs 轿车、住 Polanco 还是 Iztapalapa。这是天生的镜头语言，比国内更好拍。
- **compadrazgo（教父母关系）** —— 墨西哥独有的准亲属契约。一个人可以因为「我是你 compadre」获得家族内部权限。这是绝佳剧情工具，国内没有对应物。
- **语言即权力**：`usted`（您）和 `tú`（你）的切换是阶级与亲密度的实时信号。男女主从 usted 转 tú 的那一刻，就是关系转折点，直接可写进剧本。

### 东南亚（SEA）—— 必须拆成 5 个国家建

把东南亚当一个市场，是本项目最大的坑。五国的宗教、法律、审查、审美差异**大于**它们和中日的差异。

| 国家 | 主体宗教 | 与「霸总公式」的兼容度 | 关键差异 |
|---|---|---|---|
| **印尼 ID** | 伊斯兰（多数） | 高（人口 2.7 亿，最大单一市场） | 男女肢体接触、酒精、跨宗教恋爱极敏感；LGBT 内容禁止 |
| **菲律宾 PH** | 天主教（亚洲最大） | **中**（离婚不合法，复仇线要重写） | OFW 海外劳工题材共鸣极强；teleserye 传统 |
| **泰国 TH** | 佛教 | 高（BL/GL 强国，题材最开放） | **王室与僧侣是刑事级红线** |
| **越南 VN** | 民间信仰 + 佛教 | 中高（家庭伦理接受度高） | 政治审查严格；ngôn tình 受众成熟 |
| **马来 MY** | 伊斯兰（多数） | 中（比印尼更保守） | 族群政治议题敏感；华语受众独立 |

**结论：第一版只做 1 国 1 题材试点，跑通再复制。** 建议印尼（人口最大、审查逻辑最清晰、可复用性最高）。

## 3. 六层素材清单（字段级）

### L0 市场底座 `MKT`

每国一份，字段固定，**建库前必须先填完，它约束后面所有层**。

| 字段 | 说明 | 示例（墨西哥） |
|---|---|---|
| 语言与变体 | 译制用什么口音/语域 | 中性拉美西语 vs 墨西哥本地西语（güey/órale/neta） |
| 宗教底色 | 主导信仰 + 渗透生活的方式 | 天主教；圣母瓜达卢佩是国民符号 |
| 法律红线 | 影响剧情的实体法 | 离婚合法（对比菲律宾：不合法） |
| 审查红线 | 平台 + 政府双层 | narco 美化、原住民刻板印象 |
| 家庭结构 | 谁有话语权 | 扩展家庭，祖母/教母权力大 |
| 阶级符号 | 一眼识别贫富的视觉元素 | 肤色、口音、车、住区、佣人 |
| 广告政策 | Meta/TikTok 拒审雷区 | 暴力、毒品、性暗示、减肥对比 |
| 付费习惯 | 单集价、充值档位 | 小额多次、运营商代扣 |
| 内容偏好 | 集数、单集时长、节奏 | 60–90 集，60–90 秒/集 |

### L1 现实素材 `REALITY`

#### L1-a 地域 `LOC`（国家 → 区域 → 城市 → 街区，四级）

必须有**阶级标注**，否则没法写「跨越」。

| 地区 | 代表城市 | 阶级画像 | 镜头价值 |
|---|---|---|---|
| 墨西哥 · 中部 | CDMX（Polanco / Santa Fe / Iztapalapa） | 金融豪门 vs 边缘劳工 | Polanco 玻璃幕墙 vs Iztapalapa 自建砖房 |
| 墨西哥 · 北部 | Monterrey | 工业豪门（钢铁/制造），口音即身份 | 干旱山地 + 重工业天际线 |
| 墨西哥 · 西部 | Guadalajara | 传统贵族、老钱、农场 | 殖民建筑、龙舌兰田 |
| 墨西哥 · 南部 | Oaxaca / Puebla | 原住民文化、手工艺、贫困 | 色彩墙、市集、织物 |
| 印尼 · 雅加达 | SCBD / Kemang / kampung | 新钱写字楼 vs 密集聚落 | 玻璃塔 vs 铁皮屋顶一街之隔 |
| 印尼 · 巴厘 | Denpasar / Ubud | 旅游外汇、外来资本 | 神庙、稻田、度假村 |
| 菲律宾 · 马尼拉 | BGC / Makati vs Tondo | 跨国资本 vs 棚户 | 天桥两侧的垂直贫富差 |
| 泰国 · 曼谷 | Siam / Thonglor / 老城区 | 新贵消费 vs 市井 | 商场巨屏 vs 巷口面摊 |
| 越南 · 河内/西贡 | 还剑湖 / 第一郡 | 政商家庭 vs 街边经济 | 法式老楼 + 摩托洪流 |

#### L1-b 场景 `SCN`

每条字段：`ID / 名称 / 本地叫法 / 所属地区 / 阶级属性 / 昼夜光线 / 可拍人数 / 典型道具 / 适配桥段 / S 等级`

墨西哥必备 25 条，核心示例：
`hacienda 庄园`（豪门祖宅，天井+长廊，最适合对峙戏）、`tianguis 露天集市`（阶级碰撞）、`iglesia 教堂`（誓言/忏悔/婚礼）、`cantina 酒馆`（男性权力场）、`quinceañera 十五岁成人礼宴会厅`（家族面子战场）、`lucha libre 摔角场`（反差/父子线）、`Santa Fe 写字楼`（商战）、`camioneta 车内`（密闭对峙，成本最低）。

东南亚必备 15 条/国，核心示例：
印尼 `masjid 清真寺外庭`、`warung 小食摊`、`mall 商场中庭`、` kampung 巷道`、`halal 认证工厂`
菲律宾 `sari-sari store 小卖部`（社区信息中枢）、`jeepney 车内`、`barangay hall 社区办事处`、`fiesta 节庆街`
泰国 `wat 寺庙`、`泰拳馆`、`夜市`、`湄南河渡船`

> **成本提示**：每条场景标「可拍人数」，直接决定 AI 生成的难度。1–2 人 + 空镜优先入公式，群戏留给高潮集。

#### L1-c 物品 `OBJ`

物品是**阶级符号的载体**，也是最好做的「换皮」素材（S1 居多）。

分四类：`身份符号` / `情感信物` / `剧情道具` / `生活质感`

墨西哥示例：
- 身份：`camioneta 皮卡`（真豪门的反符号，开皮卡比开跑车更有老钱味）、`sombrero`（挑对了是身份，挑错了是冒犯）、`Rolex`、`rancho 地契`
- 信物：`Virgen de Guadalupe 吊坠`、`rebozo 手工披肩`、`祖母的 rosario 念珠`
- 剧情：`acta de matrimonio 结婚证`、`testamento 遗嘱`、`prueba de ADN 亲子鉴定报告`
- 生活：`molcajete 石臼`、`comal 烙饼铁板`、`nopal 仙人掌`

东南亚示例（印尼）：`batik 蜡染衬衫`（正式场合身份）、`kopiah 小帽`、`ojek 摩托`、`rumah makan padang 巴东饭馆`、`halal 标识`、`mukena 祈祷服`、`angpau 红包`
菲律宾：`sari-sari 挂袋零食`、`jeepney 车头装饰`、`balikbayan box 海外包裹`（OFW 叙事的核心情感物）

#### L1-d 宗教与民俗节点 `REL`

这一层是**节日 = 天然剧情节点**，也是审查雷区。

| 市场 | 节点 | 剧情用法 | 风险 |
|---|---|---|---|
| MX | Día de Muertos（11/1–2） | 灵前对峙、亡者秘密、家族和解 | 低 |
| MX | Virgen de Guadalupe（12/12） | 誓言、救赎、贫民共鸣 | 低，但不可戏谑 |
| MX | quinceañera | 阶级攀比、身份揭穿 | 低 |
| MX | posadas（12月） | 家族团聚、逼婚压力 | 低 |
| ID/MY | Idul Fitri + mudik 返乡 | **最强共鸣点**：全城返乡、阶级在村口现形 | 中，仪式细节必须准确 |
| ID/MY | 斋月 | 白天禁食→情绪紧绷，夜晚集市 | 中 |
| PH | 圣诞季（9月起，全球最长） | 家族全到场，冲突集中 | 低 |
| PH | fiesta 村节 + 选美 | 社区权力斗争 | 低 |
| TH | 做功德、出家短期仪式 | 救赎、洗罪 | **僧侣形象不可冒犯** |
| VN | Tết 春节 | 债务清算、返乡压力 | 中 |

#### L1-e 语言与台词库 `DIA`

**这是最容易做、收益最高的一层。** 建四类：

1. **称谓系统**——谁怎么叫谁，暴露关系与阶级
   墨西哥：`usted/tú` 切换、`señora/señorita`、`jefe`、`compadre`、`mi amor` vs `corazón`
   印尼：`Bapak/Ibu`（尊称）、`Mas/Mbak`（爪哇）、`kamu/Anda`、亲属称谓泛化（`Om/Tante` 叫非亲属）
   菲律宾：`po/opo`（敬语，无法直译）、`Kuya/Ate`、`Sir/Ma'am`
   泰国：`พี่/n้อง`（哥姐弟妹系统，几乎所有人际关系都用）、`ครับ/ค่ะ` 句尾敬语

2. **情绪爆点句**——打脸/告白/决裂各 10 条本地化版本（不能直译，要重写）
3. **阶层标记词**——同一个意思的富人说/穷人说
4. **禁忌词表**——各国不能说、不能拍的词

> 台词库不是翻译表，是**语气采样库**。产剧本时用它校准语域，而不是当句库直接抄。

#### L1-f 镜头语言 `CAM`

按当地观众习惯和成本标注：
`近景对峙`（最便宜）、`车内双人`、`背影走位`、`空镜情绪`（skyline/雨/门廊）、`群像宴会`（最贵，限高潮集）、`监控视角`（真相揭穿标配）

每国补 3–5 个**本地审美偏好**：墨西哥爱暖调土色与强反差光；印尼爱明亮饱和与家庭暖光；泰爱柔焦与都市冷调。

### L2 叙事要素 `NARRATIVE`

#### L2-a 题材 `GEN`

第一版只锁定一条：**豪门阶级跨越 + 打脸复仇**。备选池先登记不建：
`隐藏身份` / `契约婚姻` / `追妻火葬场` / `双胞胎错位` / `复仇归来` / `代嫁` / `认亲`

每个题材字段：`核心欲望 / 核心恐惧 / 道德前提 / 目标市场适配度 / S 等级`

#### L2-b 人设 `CHR`

人设必须**结构化**，否则写不出稳定性格。每个角色一张卡：

```
CHR-MX-001  男主·冷面继承者
├─ 阶级位置：老钱（第三代）
├─ 表面人格：控制、寡言、礼数精准
├─ 真实缺陷：无法承认需要别人（源于母亲缺席）
├─ 秘密：接班是被设计的，真继承人是别人
├─ 说话方式：短句，称对方 usted 直到第 18 集
├─ 视觉符号：皮卡、旧手表（祖父遗物，非奢侈品）
├─ 剧情功能：阻碍者 → 镜像角色 → 同盟（三段位移）
├─ 不可做：不会哭、不会当众失态（破坏人设）
└─ S 等级：S1（外壳可换，内核通用）
```

**关键：每个角色必须写「不可做」清单。** 这是保证性格一致性的唯一硬手段。没有这条，写到第 30 集人物必然崩。

人物类型分四档：
- 主角（1–2）
- 功能配角：`阻碍者` / `助攻者` / `信息携带者` / `镜像角色` / `道德裁判`
- 家族长辈（决定 L0 家庭结构）
- 群像背景（宴会宾客、公司员工、街坊）

墨西哥专属原型：`la abuela 掌权祖母`、`el patrón 庄园主`、`la sirvienta 女佣`（常是信息枢纽，别写成工具人）、`el compadre 教父`
东南亚专属原型：印尼 `Ibu kos 房东太太`、`ustad 宗教导师`、`anak kampung 街坊孩子`；菲律宾 `OFW 归国母亲`、`barangay captain 社区长`

#### L2-c 关系与主线 `ARC`

主线不给散文大纲，给**事件链**：`事件 → 状态变化 → 下一事件`

五段式骨架（60 集压缩）：
1. `契约绑定`（1–8）— 利益/胁迫促成绑定
2. `误会升级`（9–24）— 信息差制造伤害
3. `真相裂缝`（25–38）— 配角泄露一个真相
4. `全面崩塌`（39–50）— 最大的谎言被当众揭穿
5. `反转/和解`（51–60）— 主角用前 50 集积累的东西反杀或放下

主线字段：`欲望对象 / 阻力层级 / 中点反转 / 最低点 / 终局代价`

**阻力必须是三层叠加**，只靠反派使坏撑不住 60 集：
`外部阻力（家族/公司）` + `内部阻力（性格缺陷）` + `结构阻力（阶级/宗教/法律）`
→ 墨西哥可加 `compadrazgo 义务`，印尼可加 `宗教/家族名誉`，菲律宾可加 `无离婚法`。

#### L2-d 支线 `SUB`

支线是**主线情绪的放大器**，不是第二故事。固定四种：
1. `镜像支线`——配角走一遍主角的路但选了另一个答案
2. `代价支线`——主角的选择伤害了无辜者
3. `信息支线`——真相是怎么泄露的
4. `和解支线`——跟父辈/过去的和解

每条支线字段：`挂载集数 / 功能 / 与主线的交叉点 / 收束集`

#### L2-e 爽点 `BEAT`

这是短剧的硬通货。分类 + 触发条件 + 位置：

| 爽点 | 触发条件 | 典型位置 |
|---|---|---|
| `当众打脸` | 反派在众人前羞辱 → 主角一句话反转 | 第 5/15/30 集 |
| `身份揭穿` | 被看低的人暴露真实身份 | 第 12/40 集 |
| `反向示弱` | 强者当众承认弱点，反而赢得尊重 | 中后段 |
| `沉默碾压` | 不吵不闹，用行动/物件压制 | 任意 |
| `错位信息` | 观众知道、角色不知道 → 观众获得优越感 | 全篇 |
| `追妻火葬场` | 男主追悔，女主已冷 | 后 1/3 |
| `打脸升级` | 打脸对象层级递增（佣人→亲戚→对手→家族） | 递进 |

**每集必须落 1 个爽点，且爽点层级不能原地重复。**

#### L2-f 钩子 `HOK`

按位置分三类，每类 15–20 条：
- `开场 3 秒钩`——信息缺口/冲突爆点/反常画面
- `集尾悬念`——新信息、新人物、新威胁
- `转折钩`——预期违背

公式化的钩子模板（可套素材）：
`[身份误判] + [即将揭穿] + [倒计时]`
例：`她被当成新来的保洁，只有他知道她是这栋楼的主人——而真正的买家一小时后到。`

---

### L3 组装公式 `FORMULA`

#### 单集模板（60–90 秒）

```
0–3s     HOK-OPEN        钩子（信息缺口）
3–15s    SCN + CHR        建立空间与关系（1–2 人）
15–50s   BEAT-CONFLICT    冲突升级（含信息差）
50–75s   BEAT-REVERSAL    打脸/翻转
75–90s   HOK-CLIFF        悬念尾巴（引出下集）
```

#### 剧本生成流程（5 步，每步输入输出明确）

1. **定市场** → 读 `MKT`，锁死 L0 红线
2. **选骨架** → 从 `ARC` 取五段式，套 `GEN`
3. **填人设** → 从 `CHR` 取 1 主角 + 1 反派 + 2 功能配角，逐条填「不可做」
4. **铺事件** → 每集分配 `BEAT` + `HOK`（禁止同一爽点层级连续两集）
5. **落地场景** → 每集从 `SCN` 选 1–2 个，从 `OBJ` 选 1 个符号物，从 `DIA` 校语域

#### 组装示例（墨西哥 · 第 3 集）

```
MKT-MX（L0）      锁定：天主教、扩展家庭、usted/tú 阶级信号
ARC-MX-001        第1段「契约绑定」
CHR-MX-001        男主·冷面继承者
CHR-MX-004        女配·掌权祖母（阻碍者）
SCN-MX-002        hacienda 天井（对峙）
OBJ-MX-011        祖父旧手表（非奢侈品，身份伏笔）
BEAT-003          沉默碾压
HOK-CLIFF-007     新威胁：真正的继承人回国
CAM-002           车内双人（成本最低）
```

→ 直接可写成分场脚本。

## 6. 建库顺序（建议）

1. **先填 L0 + 红线表**（半天，但决定后面全部）
2. **再建 L1-e 台词库 + L1-b 场景库**——这两层投入产出比最高，直接能出片
3. **L2 人设 + 爽点 + 钩子**（可平行）
4. **L3 公式试跑**：用现有素材硬写 3 集完整剧本，验证零件够不够
5. **缺口回填**——试跑暴露的缺口，才是真需求
6. 印尼跑通后，复制 schema 到墨西哥（L0 换掉，L1 换掉，L2 大部分可复用）

> **不要先建完所有素材再写剧本。** 写到卡住的时候，才知道缺什么。第 4 步不能省。

## 7. 已知风险

1. **东南亚拆国成本高** —— 五国等于五个库。建议只做印尼 + 菲律宾（人口 + 付费结构最好的两个），其余用「印尼骨架 + 局部替换」降级处理。
2. **S2 误判** —— 把需要重写的当换皮。建议每条 S2/S3 素材由当地人复核一次，找不到人就用「保守写法」兜底。
3. **公式僵化** —— 跑顺之后会所有剧一个味。预留一个「每 10 集允许 1 次偏轨」的机制。
4. **宗教细节出错** —— 印尼/马来/泰的仪式细节错一处，评论区就炸。宁可模糊处理，不要写细节猜。
