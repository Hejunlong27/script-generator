# MX · 台词绑定场景（分场稿半成品）

> `05-dialogue.md` 是句库，这一份是**句库 × 场景**的绑定表。
> 写分场时不用再从零想「这个场景该说什么」，直接查表。

**共 14 个高频场景。每个给出：权力关系 → 配什么道具 → 可用台词 → 分场示范。**

## 01 · MX-SCN-008 佣人厨房 `cocina de servicio`

**权力关系**：佣人的地盘。主人走进来本身就是侵犯；反过来说，这里说的话才是真话。
**配道具**：MX-OBJ-010 石臼 · MX-OBJ-011 comal · MX-OBJ-018 婚纱
**冲突类型**：结盟 / 偷听 / 摊牌

| 台词 | 中文 | 用法 |
|---|---|---|
| `Aquí se habla de otra cosa, señora.` | 在这儿说的不是那套话，太太 | 佣人对主人，划地盘 |
| `Yo no vi nada. Y usted tampoco.` | 我什么都没看见。您也什么都没看见 | 结盟，双向封口 |
| `¿Cuántos años lleva aquí? — Los mismos que usted tiene de casada.` | 你在这儿多少年了？——跟您结婚的年头一样长 | 用时间反压，杀伤力极大 |

**分场示范**
```
INT. COCINA DE SERVICIO — NOCHE
她背对镜头，用石臼磨酱。主人站在门口。
主人：¿Sigues aquí?
她没回头：Aquí estoy desde antes que usted.
（她继续磨。磨声变大。）
```

## 02 · MX-SCN-009 豪宅厨房 `cocina principal`

**权力关系**：主人和佣人共处，但各有各的厨房。这个设定本身就是阶级。越界对手戏的最佳舞台。
**配道具**：MX-OBJ-010 石臼 · MX-OBJ-016 蜡烛
**冲突类型**：夜谈 / 关系推进 / 示弱

| 台词 | 中文 | 用法 |
|---|---|---|
| `Ya no me digas patrón.` / `¿Entonces?` / `Dime tú.` | 别再叫我老爷 / 那叫什么 / 叫我「你」 | **全剧最贵的三句**，称谓转折点 |
| `¿Por qué haces esto? — Porque es lo único que en esta casa se sigue haciendo como mi abuela.` | 你为什么做这个？——因为这是这栋房子里唯一还照我祖母方式做的事 | 用能力而非位置赢尊重 |
| `No tengo hambre. — No le pregunté.` | 我不饿。——我没问你 | 短、硬、关心藏在粗暴里 |

**分场示范**
```
INT. COCINA PRINCIPAL — MADRUGADA
她磨酱。他在门口站了半分钟才开口。
他：Ya no me digas patrón.
她停下手，没抬头：¿Entonces?
他：（停顿）Dime tú.
（她继续磨。磨声比刚才响。）
```

## 03 · MX-SCN-002 豪宅客厅 `sala de la casa grande`

**权力关系**：家族审判场。谁站着、谁坐着、谁被叫进来，都是判决。
**配道具**：MX-OBJ-034 旧照片 · MX-OBJ-004 念珠 · 家族合影
**冲突类型**：审问 / 羞辱 / 和解

| 台词 | 中文 | 用法 |
|---|---|---|
| `Siéntate. — Prefiero estar de pie.` | 坐下。——我宁愿站着 | 拒绝坐下 = 拒绝被审 |
| `Tú no eres de esta familia. — Nunca dije que lo fuera.` | 你不是这家人。——我从没说过我是 | 最狠的软钉子 |
| `Estaba ocupado.` | 我在忙 | **回旋镖**：第 1 集他这么说，最后一集别人这么说他 |

**分场示范**
```
INT. SALA — TARDE
全家坐着。她站在中间，没人让她坐。
祖母：Siéntate.
她：Prefiero estar de pie, señora.
（长时间的沉默。祖母没有再让。）
```

## 04 · MX-SCN-014 大宅书房 `despacho`

**权力关系**：真正的权力在这里，不在客厅。谈判、威胁、签文件都在这一间。
**配道具**：MX-OBJ-006 遗嘱 · MX-OBJ-036 账本 · MX-OBJ-025 雪茄
**冲突类型**：谈判 / 威胁 / 权力交接

| 台词 | 中文 | 用法 |
|---|---|---|
| `¿Ya terminó? — Usted.` | 说完了吗？——「您」 | 当众打脸只回一个 usted |
| `No te voy a hacer nada. Vas a hacerlo tú.` | 我不会对你做什么。你会自己做的 | 心理压迫，不用动手 |
| `Sé dónde duerme tu mamá.` | 我知道你妈妈睡哪儿 | 墨西哥式威胁：不说狠话，说生活细节 |

**分场示范**
```
INT. DESPACHO — NOCHE
他一直在说，说了很久。她一句没插。
他停下来喘气。
她：（等了三秒）¿Ya terminó?
他：¿Qué?
她：Usted.
（她起身走了。他一个人坐着。）
```

## 05 · MX-SCN-016 后院洗衣区 `patio de lavado`

**权力关系**：主人在屋里，佣人在后院。一墙之隔，是两个世界。全剧最好的密谈场。
**配道具**：MX-OBJ-019 围裙 · 搓衣板 · 晾衣绳
**冲突类型**：密谋 / 崩溃 / 交底

| 台词 | 中文 | 用法 |
|---|---|---|
| `Aquí nadie nos oye.` | 这儿没人听得见我们 | 密谈开场 |
| `Si te vas, ¿quién lava?` | 你要是走了，谁洗？ | 用活计留人，最冷的挽留 |
| `No le digas a nadie. Ni a tu madre.` | 别告诉任何人。连你妈都别说 | 拉美语境里「别告诉你妈」是最高级别的封口 |

**分场示范**
```
EXT. PATIO DE LAVADO — DÍA
两人隔着水泥池，一个洗一个晾。全程不看对方。
她：¿Se lo dijiste?
另一人：No le digas a nadie. Ni a tu madre.
（她把湿衣服拧得更用力。）
```

## 06 · MX-SCN-004 教堂 `iglesia`

**权力关系**：唯一一个所有人都必须低头的空间。所以在这里说真话最有重量，也最危险。
**配道具**：MX-OBJ-004 念珠 · MX-OBJ-017 亡者照片 · MX-OBJ-018 婚纱
**冲突类型**：誓言 / 揭穿 / 忏悔

| 台词 | 中文 | 用法 |
|---|---|---|
| `Lo juro por mi madre.` | 我以我母亲起誓 | 拉美最高规格发誓。说了就必须兑现 |
| `Dios ve todo. — Pero usted no.` | 上帝什么都看得见。——但您看不见 | 反驳权威，极狠 |
| `Perdóname. — ¿Por qué ahora?` | 原谅我。——为什么是现在 | **原谅必须迟到**，早原谅就没戏 |

**分场示范**
```
INT. IGLESIA — DÍA
婚礼进行到一半。她停下来。
她：Lo juro por mi madre.
（她看向后排的一个人。那个人低下了头。）
```

## 07 · MX-SCN-012 宴会厅 `salon de quinceañera`

**权力关系**：全家族的阶级图谱。谁坐哪一桌、谁被安排在门边，都是公开处刑。
**配道具**：MX-OBJ-009 地契 · MX-OBJ-007 亲子鉴定 · 蛋糕
**冲突类型**：当众打脸 / 身份揭穿 / 群戏高潮

| 台词 | 中文 | 用法 |
|---|---|---|
| `Me llamaste sirvienta. Y lo fui. Pero a ti te llamaron esposa y no lo eres.` | 你叫我女佣，我确实是。可他们叫你太太——你不是 | 全剧级反击 |
| `Que pase. — ¿Aquí? — Aquí.` | 让她进来。——在这儿？——就在这儿 | 主动把冲突拉到公开场合 |
| `Este edificio es mío desde hace tres años.` | 这栋房子三年前就是我的了 | 配 MX-OBJ-009 地契，当众推过去 |

**分场示范**
```
INT. SALÓN — NOCHE
全场举杯。真千金站起来，笑着说了句什么。
她放下杯子，从手袋里取出一张纸，推过桌面。
她：Me llamaste sirvienta. Y lo fui.
（那张纸停在桌子中央。最近的人先低头去看。）
```

## 08 · MX-SCN-015 董事会 `sala de juntas`

**权力关系**：长桌座次就是权力顺序。开会戏靠位置不靠台词。
**配道具**：MX-OBJ-006 遗嘱 · MX-OBJ-036 账本 · 股权文件
**冲突类型**：夺权 / 投票 / 逐条清算

| 台词 | 中文 | 用法 |
|---|---|---|
| `Yo no vine a pedir. Vine a cobrar.` | 我不是来要的。我是来收的 | 开场第一句就定调 |
| `¿Alguien más quiere revisar las cuentas?` | 还有谁想查账？ | 反问，全场不敢应 |
| `No sé leer. Por eso traje al notario.` | 我不识字。所以我带了公证人 | 反向示弱，把弱点变武器 |

**分场示范**
```
INT. SALA DE JUNTAS — DÍA
她最后一个进来，站在桌尾，不坐。
她：Yo no vine a pedir. Vine a cobrar.
（她把账本放下。桌子那头有人合上了笔记本。）
```

## 09 · MX-SCN-031 律师办公室 `despacho del licenciado`

**权力关系**：文件比人硬。这里决定的事，客厅里吵不回来。
**配道具**：MX-OBJ-006 遗嘱 · MX-OBJ-007 亲子鉴定 · 公文包
**冲突类型**：宣读 / 交易 / 反转底牌

| 台词 | 中文 | 用法 |
|---|---|---|
| `Firme aquí. — Antes quiero leerlo.` | 签这儿。——我想先读一遍 | 拒绝盲签 = 夺回主动 |
| `Hay dos testamentos.` | 有两份遗嘱 | 一句话开后 20 集 |
| `¿Usted de qué lado está, licenciado?` | 律师，您站哪一边？ | 逼人表态，最有效的逼问 |

**分场示范**
```
INT. DESPACHO DEL LICENCIADO — DÍA
他把文件推过来，笔已经放在上面。
她没接笔：Antes quiero leerlo.
他：Son treinta páginas.
她：Entonces siéntese.
```

## 10 · MX-SCN-032 公证处 `notaria publica`

**权力关系**：不可逆的地方。按手印、盖钢印，做了就不能反悔。
**配道具**：钢印 · 印泥 · MX-OBJ-009 地契 · MX-OBJ-008 结婚证
**冲突类型**：签字 / 反转 / 最后的底牌

| 台词 | 中文 | 用法 |
|---|---|---|
| `Presione aquí. — ¿Ya no hay vuelta atrás? — Ninguna.` | 按这儿。——不能反悔了？——不能 | 把「不可逆」说出来 |
| `Este sello tiene fecha de hace tres años.` | 这个钢印的日期是三年前的 | 时间诡计被拆穿 |
| `¿Quién firmó como testigo?` | 谁签的见证人？ | 一句问话引爆全剧 |

**分场示范**
```
INT. NOTARÍA — DÍA
公证人把印泥推过来。她的手停在半空。
公证人：Presione aquí.
她：¿Ya no hay vuelta atrás?
公证人：Ninguna.
（她的手按下去。镜头切到见证人那一栏的签名——是她父亲的名字。）
```

## 11 · MX-SCN-033 法院走廊 `pasillo del juzgado`

**权力关系**：真正的交易在开庭前十分钟谈完。所以走廊比法庭好用。
**配道具**：长椅 · 公告栏 · 卷宗
**冲突类型**：私下交易 / 证人相遇 / 最后通牒

| 台词 | 中文 | 用法 |
|---|---|---|
| `Retira la demanda y esto se queda entre nosotros.` | 撤诉，这事就我们之间了 | 走廊交易的标准句式 |
| `Te vi. Ese día, yo estaba ahí.` | 我看见你了。那天，我就在那儿 | 证人自曝，最炸的一句 |
| `No te voy a mentir. Vas a perder.` | 我不骗你。你会输 | 反向劝退，比威胁有效 |

**分场示范**
```
INT. PASILLO DEL JUZGADO — DÍA
两人坐在长椅两端，中间隔着三个空位。
他：Retira la demanda y esto se queda entre nosotros.
她没转头：No te voy a mentir. Vas a perder.
（法警喊号。她先站起来，走了。）
```

## 12 · MX-SCN-020 移民局面谈室 `sala de entrevista migratoria`

**权力关系**：官方空间。一个程序性问题就能炸出一段假婚姻。
**配道具**：MX-OBJ-023 签证材料 · MX-OBJ-008 结婚证 · 表格
**冲突类型**：验真 / 露馅 / 被迫坦白

| 台词 | 中文 | 用法 |
|---|---|---|
| `¿Qué comieron el día que se conocieron?` | 你们第一次见面吃了什么？ | **本场景最好用的一句**，两人答案不一致就全塌 |
| `¿Duerme del lado de la pared o de la orilla?` | 你睡靠墙那侧还是床边？ | 只有真夫妻才答得上的问题 |
| `¿Cuántos años tiene su suegra?` | 你婆婆多大年纪？ | 一个数字就能验穿 |

**分场示范**
```
INT. SALA DE ENTREVISTA — DÍA
官员头也不抬地翻表格。
官员：¿Qué comieron el día que se conocieron?
两人同时开口。（字幕分成两行，两个不同的答案）
官员抬起头。
```

## 13 · MX-SCN-005 皮卡车内 `camioneta`

**权力关系**：密闭空间，谁都下不去。成本最低的强戏场。
**配道具**：MX-OBJ-022 护照 · MX-OBJ-029 缝进衣内的东西 · 后视镜
**冲突类型**：对峙 / 私下谈判 / 逃亡

| 台词 | 中文 | 用法 |
|---|---|---|
| `Bájate. — No.` | 下车。——不 | 两句话立冲突 |
| `¿Adónde me llevas? — A donde no te busquen.` | 你带我去哪儿？——去没人找你的地方 | 保护还是绑架，故意含糊 |
| `（沉默 + 从后视镜看对方）` | — | **后视镜里的对视比对话狠**，写进剧本 |

**分场示范**
```
INT. CAMIONETA — NOCHE (MOVING)
他开车。她坐后座。两人都没说话。
她在后视镜里看他。他也在看她。
（谁先移开视线，谁就输了。她先移开。）
```

## 14 · MX-SCN-021 墓地 `panteon`

**权力关系**：唯一一个所有人都平等的地方。所以在这里和解、揭穿、告别都成立。
**配道具**：MX-OBJ-017 亡者照片 · MX-OBJ-013 万寿菊 · MX-OBJ-019 围裙
**冲突类型**：真相 / 告别 / 收束

| 台词 | 中文 | 用法 |
|---|---|---|
| `Ya está. Ya puedes descansar.` | 好了。你可以歇了 | 收束集标准句 |
| `Me debes una explicación, y ya no te la voy a pedir.` | 你欠我一个解释。我不会再问你要了 | 放下 = 更狠的追责 |
| `No vine a despedirme. Vine a devolverte esto.` | 我不是来告别的。我是来还你这个的 | 配念珠/围裙，收束必备 |

**分场示范**
```
EXT. PANTEÓN — AMANECER
她站在墓前。手里拿着念珠。
她把念珠放在台阶上，没有跪。
她：No vine a despedirme. Vine a devolverte esto.
（她脱下围裙，放在念珠旁边，走了。镜头停在围裙上。）
```

## 使用说明

1. **先定场景，再挑台词**。反过来会写出「哪都能放」的废句。
2. **每场 1 个道具**。道具是这场戏的记忆点，超过两个就散。
3. **台词表里带 `—` 的对答必须成对使用**，拆开就不成立。
4. **分场示范是格式样本，不是成稿**。照着它的节奏写自己的内容，不要抄内容。
