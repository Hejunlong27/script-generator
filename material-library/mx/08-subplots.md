# MX · 支线 SUB 层（32 条）

**支线不是第二个故事，是主线情绪的放大器。**

四条支线并行，各司其职。每部剧**只允许每类选 1 条**——选两条同类，60 集会变成两锅粥。

| 类 | 干什么 | 在哪个段展开 |
|---|---|---|
| **S1 镜像** | 配角走一遍主角的路，但选了另一个答案 | 段 2–3（9–38 集） |
| **S2 代价** | 主角的选择伤害了无辜者 | 段 3–4（25–50 集） |
| **S3 信息** | 真相是怎么泄露的 | 全篇分 3–4 次释放 |
| **S4 和解** | 跟父辈、跟过去、跟自己 | 段 5（51–60 集） |

## 60 集排布图（照这个铺）

```
段1 契约绑定   1–8    S3 埋下第 1 次线索（SUB-021 发现信）
段2 误会升级  9–24    S1 展开（SUB-001 女佣劝她走）
                      S3 第 2 次释放（第 12 集旧照片）
段3 真相裂缝 25–38    S2 展开（SUB-009 女佣首领被辞退）
                      S3 第 3 次释放（第 29 集账本）
段4 全面崩塌 39–50    S2 代价结算（第 45 集全村人上门）
                      S3 最后一次释放（第 46 集全部念出）
段5 反转和解 51–60    S4 收束（SUB-025 念珠 + SUB-029 真名）
                      S2 余波（第 53 集给女佣一份工作）
```

### 四条铁律

1. **S3 信息支线必须分成 3 次以上释放**。一次给完，后面 30 集没东西可揭。
2. **S2 代价支线必须在段 3 之前埋好**。等到第 45 集才出现代价，观众会觉得是硬加。
3. **S1 镜像支线必须有一个人明确站在主角对面说「你错了」**。没有这个对峙，镜像就是背景板。
4. **S4 和解不得取消任何冲突**。和解是承认，不是抹平。**最差的结局就是所有人都被原谅了。**
