# MX · L0 市场底座与红线

**填任何素材之前先读这一页。它约束后面所有内容。**

---

## 一、核心底数

| 项 | 内容 |
|---|---|
| 语言 | 墨西哥西班牙语（es-MX）。**不要用中性拉美西语**——本地观众一听就出戏。用 `güey / órale / neta / chido / pinche` 这套 |
| 宗教 | 天主教（名义 78%）。圣母瓜达卢佩是国民符号，不可戏谑 |
| 家庭结构 | 扩展家庭。祖母（abuela）有实权，教母（madrina）/ 教父（compadre）是准亲属，一句话就能进别人家门 |
| 阶级符号 | 肤色、口音、车、住区、佣人。**这四样一眼分贫富，是天生的镜头语言** |
| 集数 | 60–90 集，60–90 秒/集 |
| 付费 | 小额多次 + 运营商代扣（Telcel/AT&T 为主） |
| 平台 | TikTok Drama Center 为主投放口；Meta/TikTok 广告审核是实际生死线 |

## 二、语言即权力（最高价值的一条）

`usted`（您）↔ `tú`（你）的切换 = 阶级与亲密度的实时信号。

- 下属对老板：永远 `usted`，直到被允许改口
- 男女主从 `usted` 转 `tú` 的那一刻 = **关系转折点**，直接写成剧本里的一个动作
- 反过来，吵架时从 `tú` 退回 `usted` = 决裂。**这个动作比任何台词都狠**

**这两个字，比一整段对白有用。**

## 三、可替换等级（每条素材必标）

| 级 | 含义 | 例 |
|---|---|---|
| S0 | 通用直用 | 董事会、手机摔碎、验孕棒、监控录像、亲子鉴定 |

## 四、红线表（S3，硬约束）

| 禁区 | 说明 |
|---|---|
| 毒枭美化 | `narco` 题材在 Meta/TikTok 广告审核里是拒审高发项。**暴力细节、炫富式毒枭美学、警察对抗，全部规避**。见 §五 的替代方案 |
| 政治人物影射 | 总统、执政党、选举。**「总统」标签必须降级为州长/市长/企业掌门** |
| 原住民刻板印象 | 把 indigenous 写成愚昧/野蛮/背景板，会招致公开批评。要写就写有主体性的人 |
| 「白皮=富、棕肤=仆」当默认审美 | 墨西哥有真实的 colorismo 问题。**这是最容易无意中踩的一条** |
| 圣母/圣像戏谑 | 可以做情感符号，不能当笑料或性暗示道具 |
| 儿童受虐细节 | 平台硬性拒审 |
| 自杀具体方式 | 平台硬性拒审 |

## 五、`narco` 怎么处理（重要）

「头目」标签是 TikTok Drama Center 里的正规选题，但直拍毒枭在投放环节会被卡死。

**可行的三条替代路径**：

1. **家族生意化** —— 不说是毒品。写「家族进出口/矿业/运输垄断」，暴力用暗示不用展示（车灯、鞋、未接来电）
2. **架空黑帮** —— 虚构家族 `la Familia`，设定在无名城市，不出现任何真实地名和执法机构
3. **反派化** —— 黑道只做反派，主角是受害者/卧底/要脱离的人。**「想离开的人」比「掌权的人」安全得多，情绪也更强**

> **判断标准：这条内容能不能投 TikTok 广告？不能就不是选题，是废案。**
> 写之前先想投放，再想剧情。

## 六、墨西哥独有的四个「颠」素材（别浪费）

这些是别的市场没有的，用好了是护城河：

| 素材 | 为什么强 |
|---|---|
| **compadrazgo 教亲关系** | 一个人可以因为「我是你 compadre」合法进入别人家、替人做决定、甚至分遗产。**背叛 compadre 的情感重量 = 背叛亲兄弟 ×2** |
| **brujería / mal de ojo 巫术与邪眼** | 「有人对她下了咒」可以作为整条线的物理动机，观众真信 |
| **quinceañera 十五岁成人礼** | 一场宴席 = 全家族的阶级审判现场。天然的群戏高潮场 |
| **mestizaje / colorismo 身份撕裂** | 「我到底是哪一边的人」是墨西哥国民级焦虑，比「我爱不爱你」更能留住人 |

## 七、口径

- 货币：`peso`（$ 与美元同符号，剧本里必须说清 `pesos` / `dólares`）
- 时间：24 小时制
- 称呼：`señora`（已婚/年长）/ `señorita`（未婚，**现在当贬义用要小心**）
- 家庭称谓泛化：陌生人之间也叫 `mija / mijo / hermano / primo`，这是拉美特有，不是语病
