# MX · 台词与称谓库

> **这一层不是句库，是语气采样库。** 写剧本时用它校准语域，不要直接抄句子。
> 直接抄的下场：语法对、语气全错，本地观众一秒听出是译制片。

---

## 一、称谓系统（最高价值的一层）

**墨西哥人用称谓而非内容表达权力关系。** 这是免费的情绪放大器。

| 场景 | 用法 | 潜台词 |
|---|---|---|
| 下对上的默认 | `usted` | 距离 + 服从。**未经允许用 `tú` 是冒犯** |
| 上对下 | `tú` | 亲近或居高临下（两者都可能是） |
| 长辈对晚辈 | `mijo / mija` | 泛化亲属称谓，陌生人之间也这么叫，不是语病 |
| 雇工称主人 | `patrón / señora` | 墨西哥庄园时代的活化石，现在仍用 |
| 教亲关系 | `compadre / comadre` | 一句话就能进别人家门。**这层关系比血缘有时更硬** |
| 服务场合 | `joven`（不分年龄） | 对服务员/店员的安全称呼，比 `señorita` 好 |
| 亲密 | `mi amor / corazón / mi vida` | 极高频，吵架时也用 |
| 母亲/父亲（口语） | `jefa / jefe` | 「我老板」= 我妈/我爸 |
| 叫人 | `¿Mande?` | **墨西哥独有**，代替 `¿Qué?`。只有墨西哥人这么说话，用对了本地感立刻上来 |

### ⚠️ 三个坑

1. **`señorita` 现在带贬义风险**，尤其对年轻女性，慎用。用 `joven` 替代。
2. **`güey` 不能对长辈用**，用了人设直接崩。
3. **`tú` 一旦给了就不能收回**——除非你就是要表达决裂（见下）。

## 二、称谓即武器（三个可直接用的桥段）

这是本库最实用的一条方法论：**不用写狠台词，只改称谓。**

### 桥段 A｜关系的开始
```
男：（一直用 usted）……Señora, ya puede retirarse.
女：（停住）Sí, patrón.
（第 18 集）
男：Ya no me digas patrón.
女：¿Entonces?
男：……Dime tú.
```
**从 `usted → tú` 的那一刻，就是全剧的关系转折点。** 不需要拥抱、不需要告白。

### 桥段 B｜决裂
```
女：（吵架到最后，突然放慢）Lo siento. No debí hablarte así.
男：（靠近）
女：（后退一步）Usted tiene razón. Yo no pertenezco aquí.
```
**从 `tú` 退回 `usted` = 关系归零。** 这一个词比任何"我们分手吧"都狠。

### 桥段 C｜当众打脸
```
反派：（当众羞辱，用 tú）
女主：（等他说完）
女主：¿Ya terminó?（停顿）Usted.
（全场安静）
```
**打完脸只回一个 `usted`，其他什么都不用说。** 这是墨西哥语境下最高级的碾压。

## 三、情绪爆点句

用法标注：`强度` 和 `用在哪`。

### 打脸 / 身份反转
| 西语 | 中文 | 用法 |
|---|---|---|
| `Usted no sabe quién soy.` / `Y nunca lo va a saber.` | 你不知道我是谁 / 而且你永远也不会知道 | 强度高。后半句是杀招，别省 |
| `¿Cuánto cuesta?` — `Usted no alcanza.` | 多少钱？——你买不起 | 强度中高。适用于被当穷人羞辱时 |
| `No me hables de usted. No te he dado permiso.` | 别对我用"您"。我没允许过 | 强度高。**反向操作**：被居高临下时，剥夺对方的敬语权 |
| `Yo no limpio tu casa. Yo soy tu casa.` | 我不是给你打扫房子的。我就是这栋房子 | 强度极高。留到高潮集 |
| `Me llamaste sirvienta. Y lo fui. Pero a ti te llamaron esposa y no lo eres.` | 你叫我女佣，我确实是。可他们叫你太太——你不是 | 强度极高。当众用 |

### 威胁（墨西哥式：不撂狠话，说生活细节）
| 西语 | 中文 | 用法 |
|---|---|---|
| `Sé dónde duerme tu mamá.` | 我知道你妈妈睡哪儿 | 强度极高。拉美威胁的经典 —— **因为家庭是核心，动家人最狠** |
| `Conozco a tu compadre.` | 我认识你的教亲 | 强度高。暗示你已经被人从内部打开 |
| `No te voy a hacer nada. Vas a hacerlo tú.` | 我不会对你做什么。你会自己做的 | 强度高。心理压迫 |
| `Ahorita.` | 马上 | **墨西哥人用 ahorita 撒谎**。说 ahorita 的时候拖长音 = 我在敷衍你 |
| `Tranquila. Ya casi.` | 别急，快了 | 强度高。用在最恐怖的场景，语气越温柔越吓人 |

### 告白 / 拉扯
| 西语 | 中文 | 用法 |
|---|---|---|
| `No te estoy pidiendo que me quieras. Te pido que me dejes quererte.` | 我没要你爱我。我只要你让我爱你 | 强度中高。虐恋标配 |
| `Ya no te espero. Ya no.` / `(Pero sigues esperando.)` | 我不等你了。真的不等了／（可你还在等） | 推拉。括号里的话让观众说 |
| `¿Por qué te fuiste?` — `Porque tú no me detuviste.` | 你为什么走？——因为你没拦我 | 强度高。一句话定责 |
| `Te odio.` / `Ya lo sé. Y aun así me quedé.` | 我恨你／我知道。可我还是留下了 | 强度极高 |

### 悔恨（追妻火葬场专用）
| 西语 | 中文 | 用法 |
|---|---|---|
| `Estaba ocupado.` | 我在忙 | **回旋镖**。第一集用它拒绝了对方，最后一集别人用它拒绝他 |
| `Ya no hay nada que decir.` | 没什么好说的了 | 结尾专用 |
| `Perdóname.` / `¿Por qué ahora?` | 原谅我／为什么是现在 | 强度高。**原谅必须迟到**，早原谅就没戏了 |

### 孩子（催泪核弹）
| 西语 | 中文 | 用法 |
|---|---|---|
| `Mamá, ¿tú eres mi mamá?` | 妈妈，你是我妈妈吗 | 强度极高。第 6 包核心台词 |
| `No le digas a mi papá.` | 别告诉我爸爸 | 让孩子成为共谋，最痛 |
| `Yo ya sé.` | 我已经知道了 | 六岁孩子说这四个字，杀伤力最大 |

## 四、阶层标记（同一个意思，两种说法）

**这是「换皮」最大的坑。** 把穷人的台词安到富人嘴里，观众立刻出戏。

| 意思 | 富人说法 | 穷人说法 |
|---|---|---|
| 等一下 | `Un momento, por favor.` | `Espérame tantito.` |
| 真的吗 | `¿En serio?` | `¿Neta?` |
| 好吧 | `De acuerdo.` | `Sale.` / `Va.` |
| 小心 | `Tenga cuidado.` | `¡Aguas!` |
| 别开玩笑 | `No es momento para bromas.` | `¡No manches!` |
| 钱 | `recursos` / `la inversión` | `lana` / `la feria` |
| 工作 | `mi puesto` / `la empresa` | `la chamba` |
| 吃饭了吗 | `¿Ya comió?`（用 usted） | `¿Ya comiste?`（用 tú） |
| 我马上到 | `En camino.` | `Ahorita llego.`（= 可能一小时后） |
| 孩子 | `mi hijo` | `mi niño` / `mijo` |

> **判断法**：富人用完整句式 + 正式词；穷人用缩短词 + 指小词（`tantito / ahorita / ratito`）。

## 五、墨西哥专属语言梗（放进剧本立刻有本地感）

| 词 | 真实含义 | 怎么用 |
|---|---|---|
| **`Ahorita`** | 「马上」= 实际上没有明确时间 | **撒谎专用词**。一场戏里说三次 ahorita，观众就知道事情不会发生 |
| **`¿Mande?`** | 「您说什么」 | 只有墨西哥用。放进第一集，本地观众秒认亲 |
| **`Güey`** | 喂/哥们（也可当脏话） | 只给年轻人、平辈、熟人之间 |
| **`Neta`** | 真的 | 表示震惊或确认 |
| **`Órale`** | 哇/快/行 | 语气全靠重音，一句话能演四种情绪 |
| **`Chido`** | 酷 | 年轻人用，中老年不用 |
| **`Pinche`** | 该死的 | 脏话。分级：`pinche` 轻，`cabrón` 中，慎用更重的 |
| **`Platicar`** | 聊天 | 拉美用，西班牙不用。用对了是本地化细节 |
| **`La jefa / el jefe`** | 我妈/我爸 | 极口语，极真实 |

## 六、禁忌词表（S3）

| 不能说 / 不能用 | 原因 |
|---|---|
| 任何亵渎圣母、圣像、圣徒的说法 | 天主教底盘，触发强烈反弹 |
| 现任总统姓名、执政党 | 政治红线 |
| `indio` 作贬义 | 种族冒犯 |
| 对原住民模仿口音当笑料 | 会招致公开批评 |
| 直接称呼毒品名称 | 广告拒审 |
| 具体自杀方式 | 平台硬性拒审 |
| `güey` 对长辈 / 对神父 | 人设与礼数双崩 |

## 七、写台词的六条规则

1. **一集不许超过 3 句完整长句。** 短剧靠动作不靠对白。
2. **每集至少一次称谓切换或称谓停顿。** 这是免费的张力。
3. **穷人用指小词，富人用完整句。** 判错了就是译制片味。
4. **威胁不说狠话，说生活细节。** 「我知道你妈睡哪儿」比「我要杀了你」恐怖十倍。
5. **孩子只说短句。** 超过八个字就不像孩子了。
6. **沉默也要写进剧本。** 墨西哥表演传统里，停顿是台词的一部分——写 `(silencio)`，不要留白。
