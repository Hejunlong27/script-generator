## 三条使用铁律

1. **先读 `00-market.md` 的红线表，再看任何素材。** 踩一次线，账号和投放一起没。
2. **每条素材都看 S 等级。** S2 是「必须重写内核」，不是「换个地名」。把 S2 当 S1 是项目里最贵的错误。
3. **爽点刻度是 1–10，不是"相邻两集不同"这么松。** 相邻差值 ≤2，每 10 集至少 1 个 ≥7，9–10 全季 ≤3 次。规则见 `06-arc.md` §三。

## 推荐入口

第一次用，从 **包 1｜顶替新娘** 开始（`01-genres.md` §三）。
它验证过：3 集试跑只用 3 个场景、3 个物品、2 个角色、0 群戏 —— **成本极低，钩子密度够**。
