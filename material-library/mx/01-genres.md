# MX · 题材标签映射与组合矩阵

对标 TikTok Drama Center 的 45 个题材标签逐一过一遍。**不看不懂能不能直接用，看能不能投广告。**

评级：`A 直接用` / `B 换皮` / `C 必须重写内核` / `D 别碰`

| 36 | 重生 | `segunda oportunidad` | C | 别用「重生」这个词。用**神迹/濒死体验/许愿**包装。宗教框架下才不违和 |
| 37 | 异能 | `poderes` | B | 走魔幻现实主义路线，不要走超英路线。异能要小、要私密、要带来痛苦 |
| 38 | 系统 | — | **D** | 中文网文独有，本地零基础。硬上必死。**直接放弃，把「系统」的功能拆进「巫术/预言/神秘人指点」** |
| 39 | 悬疑 | `suspenso` | A | 墨西哥悬疑底子好。做「谁是凶手」不如做「谁是亲人」——身份悬疑 > 案件悬疑 |
| 40 | 穿越 | `viaje al pasado` | C | 不接受「穿越异世界」。可接受**回到 1980s / 回到出事那天**。时间跨度必须短，且要有回不去的代价 |
| 41 | 三角恋 | `triángulo amoroso` | A | 拉美核心。**关键是谁先放手**，不是谁赢 |
| 42 | 逆袭 | `superación` | A | 阶级跨越。墨西哥版逆袭必须付出「背叛自己出身」的代价，否则不真实 |

## 二、汇总：哪几个是金矿

| 类别 | 标签 | 理由 |
|---|---|---|
| **本土护城河** | 神医、玄幻→魔幻现实主义、异能、替身、伦理、怀孕 | 墨西哥有真文化根基，别人抄不像 |
| **危险区** | 头目、总统、系统 | 头目要改造，总统是 D，系统直接放弃 |
| **必须重写内核** | 马甲、团宠、大女主、重生、古风、Alpha、阿尔法狼人、超级英雄、穿越 | 直译即废片，换概念才活 |
| **性价比最高** | 替身、出轨、虐恋、怀孕、复仇、闪婚、伦理 | 拉美观众的本命菜，成本低，留存高 |

## 三、组合包（这是能直接开工的单元）

每个包 = 标签组合 + 场景需求 + 核心钩子 + 一句话卖点。
**场景 ID 见 `02-scenes-objects.json`，钩子 ID 见 `03-hooks-beats.json`。**

### 包 1｜顶替新娘（最优先做）
`替身 + 豪门 + 虐恋 + 复仇 + 伦理`

- **卖点**：拉美市场最认的一套，观众预期现成，不用教育
- **核心钩子**：新娘跑了，女佣穿上婚纱走进教堂。十年后她成了女主人，真千金跪在她面前叫「妈妈」
- **场景**：MX-SCN-001 hacienda 天井、MX-SCN-004 教堂、MX-SCN-008 佣人厨房、MX-SCN-012 quinceañera 宴会厅
- **物品**：婚纱、祖母的念珠、遗嘱、亲子鉴定
- **投放钩**：前 3 秒直接切「穿婚纱的女人在洗手间撕掉一张身份证」

### 包 2｜想脱离的黑道媳妇
`头目 + 禁忌恋 + 复仇 + 马甲（改双重身份）`

- **卖点**：符合平台选题，但走「想离开的人」路线，广告可投
- **改写**：不出现毒品、不出现真实执法机构。犯罪用「家族进出口生意」指代
- **核心钩子**：她嫁进来那天就知道自己嫁给了谁。第七年她怀了孩子，第一次想跑——而丈夫把她的护照缝进了自己的外套内衬
- **场景**：MX-SCN-014 大宅书房、MX-SCN-005 车内、MX-SCN-018 边境公路、MX-SCN-022 洗衣房
- **投放钩**：开场是她在数药片，镜头拉远——她在数的是丈夫外套里缝着的护照位置

### 包 3｜假绿卡新娘
`闪婚 + 一夜情 + 怀孕 + 千金 + 出轨`

- **卖点**：墨西哥独有加成。「为签证结婚」在这里是全民共识，动机不用解释
- **核心钩子**：她为了签证嫁给一个陌生男人。移民局面谈前一晚，她发现自己怀的孩子，是这个男人的弟弟的
- **场景**：MX-SCN-020 移民局面谈室（改造自写字楼）、MX-SCN-003 廉价公寓、MX-SCN-007 小酒馆
- **物品**：结婚证、签证材料、孕检单

### 包 4｜巫医治不了的病
`神医 + 异能 + 豪门 + 扮猪吃虎 + 悬疑`

- **卖点**：**墨西哥最强差异化。** 别人拍不了，因为没有 curandero 这个文化底盘
- **核心钩子**：豪门太太花三百万请了全国最好的医生，全都说查不出病。最后是后厨洗碗的老太太摸着她的头说：你不是病了，你是被人念了名字
- **场景**：MX-SCN-009 豪宅厨房、MX-SCN-016 后院/天井、MX-SCN-025 草药铺
- **物品**：鸡蛋（limpia 净身用）、草药束、蜡烛、亡者照片
- **注意**：仪式细节必须准确，建议当地人复核

### 包 5｜庄园年代
`年代 + 将军 + 千金 + 复仇 + 古风（改殖民/革命时代）`

- **卖点**：服化道成本高，但拉美观众对「庄园时代」有集体怀旧
- **核心钩子**：1910 年，庄园主的女儿爱上了马夫。父亲把马夫吊死在谷仓——三十年后，一个自称是他儿子的男人回来了
- **场景**：MX-SCN-001 hacienda、MX-SCN-011 谷仓、MX-SCN-004 教堂
- **风险**：成本最高，建议放第二季

### 包 6｜这个孩子不是你的
`萌宝 + 怀孕 + 总裁 + 团宠 + 伦理`

- **卖点**：催泪核弹组合。萌宝 + 抱错 + 认亲，拉美观众的眼泪开关
- **核心钩子**：女儿六岁生日那天，幼儿园做了血型检测。她看着报告单上的 O 型，想起自己是 AB 型——而她丈夫，也是 AB 型
- **场景**：MX-SCN-012 宴会厅、MX-SCN-026 幼儿园门口、MX-SCN-002 豪宅客厅
- **投放钩**：开场是生日蛋糕上的蜡烛被吹灭，字幕：`O 型`

### 包 7｜丈夫的手机里有一个我
`悬疑 + 出轨 + 伦理 + 重生（改神迹/濒死）`

- **卖点**：身份悬疑 > 案件悬疑，这是墨西哥的偏好
- **核心钩子**：丈夫死后，她解锁他的手机。相册里有 4000 张她的照片，全部拍自她不知道的角度——但他三年前就失明了
- **场景**：MX-SCN-002 豪宅客厅、MX-SCN-023 卧室、MX-SCN-011 谷仓
- **投放钩**：手机屏幕特写，时间戳全部是丈夫失明之后

### 包 8｜替身演成了自己
`娱乐圈 + 替身 + 禁忌恋 + 逆袭 + 心动拉扯`

- **卖点**：元叙事（剧里拍剧），成本可控（拍摄现场本来就有的东西）
- **核心钩子**：她是影后的替身，专门演被打的镜头。影后死了，制片人让她顶着这张脸活下去——包括嫁给影后的丈夫
- **场景**：MX-SCN-030 摄影棚、MX-SCN-002 豪宅客厅、MX-SCN-006 化妆间
- **投放钩**：有人喊「替身就位」，她挨了一巴掌，嘴角流血，导演喊「这条过了」——然后镜头给她一个人擦血

## 四、组合规则（写新剧时照这个来）

1. **必须 1 个「身份错位」标签**（替身/马甲/双重身份/重逢）+ **1 个「关系越界」标签**（出轨/禁忌恋/三角恋）+ **1 个「代价」标签」（怀孕/复仇/伦理）
   → 这三者是钩子、张力、后劲，缺一个就散
2. **不要同时用两个以上「C 级」标签** —— 每个 C 级都要重写内核，叠两个以上必崩
3. **D 级标签（总统、系统）不参与任何组合**
4. **每部剧只允许 1 个「超自然」元素**。魔幻现实主义的力量来自「只发生一件怪事」，加第二件就变成玄幻，本地观众立刻不信
