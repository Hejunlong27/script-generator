# MX · 主线骨架与试跑验证

用**包 1｜顶替新娘**（`替身 + 豪门 + 虐恋 + 复仇 + 伦理`）做完整骨架。
选定理由：拉美观众预期现成，不用教育市场，成本最低。

---

## 一、主线五段（60 集）

### 段 1｜契约绑定（1–8）

| 集 | 事件 | 状态变化 |
|---|---|---|
| 1 | 真千金的婚礼当天逃走。管家把女佣推进更衣室：你穿上 | 女佣变成太太，但没有任何人告诉她为什么是她 |
| 2 | 洞房夜，男主在书房睡。她在婚房坐到天亮 | 婚姻成立，关系为零 |
| 3 | 祖母把念珠交给她，说「你现在是这个家的人了」 | 她获得最低限度的承认 |
| 4 | 教父（compadre）上门「道贺」，眼神不对 | 观众知道有人安排了这一切，女主不知道 |
| 5 | 她在床底发现婚纱，不是她的尺码 | 第一个信息缺口 |
| 6 | 男主的旧手表被她擦桌子时摔了。他第一次发火 | 关系第一次跌到负值 |
| 7 | 真千金回来了，站在门口，穿她十五年前丢的鞋 | 两个女人第一次同框 |
| 8 | 祖母说：这个家只需要一个女主人 | **绑定完成，威胁出现** |

**段末状态**：女主在位置上，但没有任何权力。真千金在外面，教父在内部。观众知道三条线，女主只知道一条。

### 段 2｜误会升级（9–24）

| 集 | 事件 | 状态变化 |
|---|---|---|
| 9–12 | 真千金「好心」住进来，一步步接管家里的事务 | 女主被边缘化 |
| 13 | 亲子鉴定报告出现（六岁女儿） | 秘密层打开 |
| 14–16 | 男主怀疑女主偷了遗嘱，把她调回厨房 | 关系倒退到原点 |
| 17 | 她在厨房用石臼做祖母的酱，祖母尝了一口哭了 | 她第一次靠「能力」而不是「位置」赢 |
| **18** | **男主叫她别再喊 patrón，改口 tú** | **称谓转折点。关系第一次正向移动** |
| 19–21 | 真千金挑拨：她告诉男主女主是为了钱 | 信任崩塌 |
| 22 | 女佣首领替她作证，被辞退 | 她第一次为别人付出代价 |
| 23 | 她怀孕了。她没说 | 信息不对等最高点 |
| 24 | 真千金宣布自己怀孕 | **双重怀孕，观众知道其中一个是假的** |

**段末状态**：女主有爱、有孕、有敌人，但没有一个人站在她这边。

### 段 3｜真相裂缝（25–38）

| 集 | 事件 | 状态变化 |
|---|---|---|
| 25–28 | 教父开始收钱，替真千金做事 | 内鬼开始动 |
| 29 | 女佣首领在洗衣房交出三十年账本 | 第一个实体证据 |
| 30 | 男主发现遗嘱上的签名是女主的字迹——她自己不记得签过 | 她成了共谋者 |
| 31–33 | 她开始查，查到三十年前谷仓的那个马夫 | 主线升级到上一代 |
| 34 | 巫医打开鸡蛋，里面是一个胎儿形状。她怀的不是一个 | 身体秘密被外部力量揭穿 |
| 35–36 | 真千金的身份被证实是假的，但她反手公布女主的秘密 | **双方同时暴露** |
| 37 | 祖母中风，说不出话 | 唯一的裁判者失效 |
| 38 | 男主在书房找到祖父旧表里的照片：照片上是年轻时的教父和女主母亲 | **女主的身世被改写** |

**段末状态**：所有人都知道一半，没有人知道全部。这是最难受、留存率最高的一段。

### 段 4｜全面崩塌（39–50）

| 集 | 事件 | 状态变化 |
|---|---|---|
| 39–41 | 家族宴会（quinceañera 场景），真千金当众揭穿女主 | 女主身份归零 |
| 42 | 男主当众要她走。他用回了 usted | **称谓退回 = 决裂** |
| 43–44 | 她走，回到 vecindad。孩子在车上（她没带出来） | 最底点 |
| 45 | 她在屋顶平台上看见远处的玻璃幕墙 | 情绪转折：从逃到反击 |
| 46–47 | 她用三十年账本，一家一家要债 | 反击开始 |
| 48 | 教父被清算，供出换孩子的全部过程 | 内部炸开 |
| 49 | 遗嘱公开，继承人是那个一直在擦地的 | 身份彻底反转 |
| 50 | 真千金被赶走。祖母去世，念珠交到女主手里 | **旧秩序终结** |

### 段 5｜反转与和解（51–60）

| 集 | 事件 | 状态变化 |
|---|---|---|
| 51–53 | 女主接管家族事务，第一件事是给女佣涨薪 | 权力落地为具体动作 |
| 54 | 男主来求，她让他站着说话 | 位置彻底对调 |
| 55–56 | 男主查出母亲当年离开的真相，第一次哭 | 缺陷被治愈 |
| 57 | 孩子的事摊开。她告诉他：这个孩子不是你的 | **最后一颗雷** |
| 58 | 他沉默很久，说：那她是不是我的，不是你说了算 | 反转 |
| 59 | 教父被带走。他在车上还在叫 compadre | 背叛者的结局 |
| 60 | 她把念珠交还给祖母的墓，脱下围裙 | **收束：不再是任何人的替代品** |

**终局代价**：她赢了位置，但没有赢得「被爱着的那个自己」。最后一个镜头停在围裙上。

## 三、试跑暴露的三个缺口 —— 已补齐

| 缺口 | 处理 | 结果 |
|---|---|---|
| 缺中介场景 | 新增 `MX-SCN-031`–`035` | 律师办公室、公证处、法院走廊、民事登记处、信贷部窗口。全部 1–2 人、室内冷光、生成难度低 |
| 缺穷人线小物件 | 新增 `MX-OBJ-042`–`049` | 工资条、赊账本、当票、汇款单、房租收据、公交卡、塑料袋装现金、孩子成绩单 |
| 爽点刻度太粗 | 15 条重标 + 新增 `MX-BEAT-016`–`025` | 共 25 条，刻度 1–10，中低强度补满 |

### 爽点刻度（1–10）怎么用

| 档 | 含义 | 用量 |
|---|---|---|
| 1–2 | 微爽：一个动作、一个眼神、一句不回答 | 占全季约 50% |
| 3–4 | 小胜：一次反驳成功、一次没被拿捏 | 铺垫用，防疲劳 |
| 5–6 | 中爽：当众打脸、局部翻盘 | 单集主落点 |
| 7–8 | 大爽：身份揭穿、关系逆转 | 每 10 集 ≤2 次 |
| 9–10 | 极爽：全剧级翻转 | **全季 ≤3 次**，放 30/45/60 集附近 |

**四条梯度铁律**
1. 相邻两集 lvl 差值 ≤ 2，禁止从 2 直接跳 9
2. 每 10 集至少 1 个 lvl ≥ 7
3. lvl 9–10 全季累计 ≤ 3 次
4. lvl 1–3 不得连续超过 4 集，否则掉速

> 上面三张组装卡的 `escalation_level` 已按新刻度改写（第 1 集 3 / 第 18 集 5 / 第 60 集 7），可直接对照。

## 四、补齐后的下一层缺口（诚实记录）

这三条不是猜的，是补完之后才看清的：

1. **8 个组合包只验证了包 1**。包 2–8 的场景需求没有逐包过一遍，可能会再暴露场景缺口。
2. **台词库有句无场**。`05-dialogue.md` 的爆点句没有绑定「用在哪个场景、配哪个道具」。写分场脚本时还得手工配。
3. **支线 SUB 层是空的**。`schema/material.schema.json` 定义了 `arc.segments`，但数据没建。四条支线（镜像/代价/信息/和解）目前只有概念，没有条目。

> **建议**：下一轮先做第 2 条（台词绑定场景），因为它直接影响能不能出分场稿；第 3 条放到跑通 10 集之后。
