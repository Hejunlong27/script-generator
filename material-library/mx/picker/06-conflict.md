# F · 冲突内核（30 选 3）

**选法**：必须选 **3 项**，且必须凑齐三层 —— **1 个外部 + 1 个内部 + 1 个结构**。
只靠反派使坏撑不住 60 集。这是本库最容易做错的一栏。

## 三层怎么搭（照这个配，不会散）

| 层 | 作用 | 缺了会怎样 |
|---|---|---|
| **外部** | 每个阶段推进剧情 | 观众看不到「下一集有什么事」 |
| **内部** | 让主角自己也是障碍 | 观众觉得主角只会挨打，不共情 |
| **结构** | 让冲突无法靠努力解决 | 观众觉得「报警/离婚/搬走」就好了，跑掉 |

### 三个推荐三件套

| 组合 | 适合 |
|---|---|
| F01 + F04 + F03 | 阶级顶替线。最稳、最便宜 |
| F09 + F19 + F10 | 逃离线。紧张感最强，注意广告审核 |
| F01 + F13 + F14 | 家族控制线。老观众最爱 |

> **同一部剧里三层不能换边**。一旦 F 项层级残缺（比如三个全是外部），60 集必然塌。
