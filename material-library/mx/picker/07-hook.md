## 选择提示

- **G01 / G03 / G07 / G12 / G13 最省成本**：1–2 人 + 1 个道具，室内就能拍。
- **G08 / G23 / G24 / G28 最贵**：需要外景或群演。
- **G 必须与 C（主线）的起点一致**。G 说的是第 0 集之前的事，C01 说「女佣顶替新娘进门」，那 G 就要拍「她走进更衣室」那一刻。

> **一条铁律**：开场钩只交代「异常」，不交代「原因」。原因留给第一集结尾。
