# 墨西哥短剧 · 选择题式素材库（8 模块 / 240 项）

**用法**：8 个模块逐项选，选完就是一部 60 集短剧的完整框架。
**难点不是选，是能不能拼**——所以有 §2 的兼容规则。跳过它，出来的必然是废案。

## 2. 兼容规则（本库的核心，不是可选项）

所有选项都标了题材标签：
`CLA` 阶级 · `FAM` 家族 · `REL` 宗教 · `CRI` 犯罪 · `SEX` 欲望 · `MON` 金钱 · `IDE` 身份 · `OCC` 职场 · `VIO` 复仇 · `SUP` 超自然

### 2.1 五个簇

| 簇 | 标签 | 核心情绪 |
|---|---|---|
| **家族** | FAM CLA MON | 我是谁的人 |
| **信仰** | REL SUP | 我有罪吗 |
| **欲望** | SEX IDE | 我想成为谁 |
| **暴力** | VIO CRI | 我要付什么代价 |
| **职场** | OCC | 我值多少 |

### 2.2 簇间兼容表

| | 家族 | 信仰 | 欲望 | 暴力 | 职场 |
|---|---|---|---|---|---|
| **家族** | ● | ● | ● | ○ | ○ |
| **信仰** | ● | ● | △ | △ | × |
| **欲望** | ● | △ | ● | ○ | ○ |
| **暴力** | ○ | △ | ○ | ● | △ |
| **职场** | ○ | × | ○ | △ | ● |

`●` 强配（天然成立） · `○` 可混 · `△` 慎配（要有理由） · `×` 不配

### 2.3 三条硬规则

1. **1 个主簇 + 最多 2 个副簇**。超过 3 个簇，观众记不住这部剧在讲什么。
2. **B / C / D 必须链式相连**：`B∩C ≥ 1` 且 `C∩D ≥ 1`。
   三项不用共有一个标签，但相邻两项必须有交集，否则内核、主线、主角是三张皮。
3. **F 必须三层齐**：1 外部 + 1 内部 + 1 结构。三个全是外部，60 集必塌。

## 3. 两个完整拼装示例

### 示例一｜安全牌（低成本、稳）

```
A30  无名小城（虚构，免考据）
B03  她替姐姐嫁进这个家，第八年才发现当初该嫁的人是她
C01  女佣顶替新娘进门 → 发现自己才是真继承人 → 把位置让给不想要它的人
D01  庄园女佣｜温顺实在｜别人给东西先退回去｜她才是真继承人
E01 + E02  掌权祖母 + 归来的真千金
F01 + F04 + F03  家族要她走 + 她自己觉得不配 + 她不配姓这个姓
G01  婚礼上撕掉身份证，照片不是她
H15  把念珠放回墓前，脱下围裙，走了
```

**标签校验**：B `FAM` → C `FAM IDE`（∩=`FAM`）→ D `CLA IDE`（∩=`IDE`），链式相连 ✅
**簇校验**：家族（主）+ 欲望（副）→ `●` ✅
**成本**：全剧核心场景 6 个，群戏 1 场，可拍人数 ≤3

### 示例二｜差异化（巫医线，别人抄不像）

```
A11  Oaxaca 中心（彩色墙面、原住民语言）
B13  巫医说她身上跟着一个东西，那东西是十年前她埋掉的那个人的
C12  巫医说她身上跟着东西 → 驱邪时挖出十年前的尸骨 → 她自己去了警察局
D05  巫医｜古怪收费随缘｜救人时把自己漏掉｜治好一个她少活一年
E01 + E19  掌权祖母 + 巫医（对位）
F01 + F19 + F25  家族要她走 + 她怕自己变成施害者 + 她的罪没法告解
G05  三个医生摇头，洗碗的老太太：有人念你名字
H21  巫医死了，她的病好了，她开始免费给村里人看诊
```

**标签校验**：B / C / D 全含 `SUP` ✅
**簇校验**：信仰（主）+ 家族 + 暴力 → 1 主 2 副 ✅
**注意**：`信仰 × 职场` 是禁区，所以这条线**不能加 OCC 项**

## 4. 选完之后的五项校验

拼错了不会当场报错，只会到第 30 集崩。所以交付前过一遍：

| # | 检查 | 不过怎么办 |
|---|---|---|
| 1 | B∩C≥1 且 C∩D≥1？（链式相连） | 换掉 D，换 D 最便宜 |
| 2 | 簇不超过 3 个？ | 砍副簇，优先砍 `OCC` |
| 3 | F 三层齐？ | 补一个内部冲突（F04/F07/F11/F15/F19/F23/F28） |
| 4 | G 与 C 的起点是同一件事？ | 换 G |
| 5 | H 回收了 G 的道具、D 的缺陷、B 的欲望？ | 换 H |
